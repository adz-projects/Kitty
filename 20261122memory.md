# Memory Systems Upgrade Changelog (2026-11-22)

This document records all changes implemented across **Memorabilia**, **Adaptive Pathway**, **BigTinyV2** (`protocol` and `daemon`), **`src-tauri`**, the **React frontend** (`src/`), and **`docs/memory-eval/`** during the 2026-11-22 memory systems session (Phases 1–4, post-phase edge-case fixes, pathway signal telemetry, and Memory Settings UI redesign).

Total workspace scope: **75 files** (**67 modified**, **8 new**).

---

## Summary by Milestone

- **Phase 1 — Correctness, Retrieval & Context Fixes**
  - Fixed cold/1-vector `corpus_mean` degeneracy in Memorabilia and small-pool/drift corpus-mean refreshes.
  - Fixed Memorabilia's 5-use decay anchor reset bug, claim-level dispute filtering against non-active/superseded propositions, and EWMA threshold runaway lift (capped at `+0.10` with empty-turn relaxation).
  - Fixed Adaptive Pathway domain inference for pools >= 3 using centered cosine, domainless `domain_weight` preservation (`1.0`), query relevance filtering on `[Maybe verify / Unsure]` lines, and embedding model/vector-length guards.
  - Fixed `BigTinyV2` chat history loading (`get_last_messages_by_session` and `get_first_user_message`) omitting `memory_block`, stripped turn attachment metadata from recall queries across both engines, increased `SharedEmbedCache` capacity to `256` (skipping cache insert on non-interactive misses), and replaced the permanent `OnceCell` `HashEmbedder` latch with a 30-second retryable probe.

- **Phase 2 — Daytime Intake Offload & Chat Memory Inspector**
  - Added daytime `Trigger::IdleMicro` (7-minute AC idle bursts) alongside dynamic `prefer_provider` cloud/chat-provider offload across `BigTinyV2`, `src-tauri`, and frontend settings.
  - Added `PassControl` limits (`max_extractions`, `skip_analogies`) and model-free 6-hour-gated `light_maintenance_tick` (plus 15-minute daemon sweep).
  - Added `SSEEventType::MemoryRecall`, DB persistence (`messages.memory_trace`), Tauri event/history forwarding (`chat://memory-recall`), and `MemoryRecallCard` inside chat `ThinkingBox` (styled as `.tool-card`) for live turns, saved history, and previous attempts.

- **Phase 3 — Retrieval Quality, Corroboration & Cross-Session Behavioral Synthesis**
  - **Memorabilia**: Added `propositions_fts` FTS5 hybrid search + RRF fusion across chunk vectors, claim vectors, and FTS5; composite relevance scoring incorporating `prop.confidence`; periodic active proposition confidence refresh; 3-source promotion for `personal`/`community` propositions (`>= 0.35`); complete-linkage clustering (`cluster_complete_linkage`) replacing single-linkage union-find; claim-level dispute checks in `promote_transient`; stored vector reuse in `probe_neighbors`; single JOIN query in analogy synthesis.
  - **Adaptive Pathway**: Sharpened behavioral/epistemic extraction rubric (removing unused `tone`/`open_topics` fields), added 10-day half-life for `Layer::Context + BeliefKind::Context` (preserving 45d for Preferences/Stances/Traits), added `staged_evidence` cross-session synthesis pipeline hooked into `idle_sweep_with`, and added standing epistemic profile floor exemption + conditioned Pass 2 DPP (excluding `cos >= 0.85` near-duplicates).

- **Phase 4 — Antisycophancy, Prompt Caching, Telemetry & A/B Eval**
  - **Adaptive Pathway**: Added `[Fresh angle]` creative novelty streak (`NOVELTY_STREAK = 4`, `NOVELTY_COOLDOWN_TURNS = 6`) via `conversation_state.last_novelty_turn`, tightened `[In tension]` / `[Worth challenging]` directives, protected directive prefixes under token-budget truncation, and added closed-loop `signal_feedback` engagement tracking.
  - **Prompt Caching & Context**: Preserved Turn 0 `first_user_row.memory_block` across Turn 0 -> Turn 1; added independent section-level diffing for Pathway, Memorabilia, and Counterpoint blocks; added Anthropic leading-only `system` hoisting (folding mid-conversation system blocks into the following user message) and a second ephemeral `cache_control` breakpoint on the penultimate history message.
  - **Eval Harness**: Ungated `memory_eval` under `#[cfg(test)]` (with LiteRT recall tests gated on `#[cfg(feature = "litert-embed")]`), added `behavioral_ab_cases.json` (16 cases across 4 categories) + offline scoring sanity test and `#[ignore]` live OpenAI-compatible A/B harness.

- **Post-Phase Fixes & Memory Settings UI Polish**
  - Clamped `SingleObservation` and unlinked `InferredPattern` extractions to `Layer::Conversation` so uncorroborated items stage via `staged_evidence` rather than skipping directly to long-lived beliefs.
  - Extended `fired_pathway_signals` to record thought-seed `worth_testing` directives.
  - Gated Linux-only `power.rs` functions cleanly on `#[cfg(not(windows))]` / `#[cfg(any(not(windows), test))]` for warning-free Windows `clippy`.
  - Extended `/api/pathway/stats` with `tested`, `contradicted`, `avg_confidence`, `staged`, and `signals` telemetry.
  - Redesigned both Adaptive Pathway and Memorabilia Settings panels around theme-token `.mem-*` card layouts, 4-tile health overviews, directive uptake pills, searchable chip-filtered browsers (replacing dense tables), indented schedule sub-options, and collapsible Developer Tools / Maintenance disclosures.

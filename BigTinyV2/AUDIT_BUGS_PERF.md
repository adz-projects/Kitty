# BigTinyV2 — LLM Orchestration Daemon Hub Audit

Scope: `BigTinyV2` — `daemon/src` (~90 files), `protocol/src`, `client/src`.
Focus: hub-conversion risks (missing `app_id` isolation, global state, cross-app leaks) + meaningful efficiency gains.
Date: 2026-09-05

## 2) Efficiency and Performance Gains

| File | Line | Code Snippet | Description | Proposed Action |
|---|---|---|---|---|
| `daemon/src/agent/loop_.rs` | 1890,1520 | `Some(tools_for_turn.clone())` | Full tool schemas (2-6k tokens) cloned on every retry/iteration inside step loop. | Pass `&tools_for_turn` / `Option<&[Value]>` to `chat_completion`; only clone when mutating. |
| `daemon/src/agent/loop_.rs` | 1551,1666,1706 | `projected_input_tokens(...)` + `count_messages_tokens(&messages)` x3-4 | Full cl100k encode of entire transcript 3-4x per iteration with no await, blocking Tokio worker tens of ms. | Keep single estimate per iteration; full recount only near `preflight_gate`, cache result. |
| `daemon/src/agent/loop_.rs` | 1865 | `let mut o = messages.clone(); o.push(seed.clone())` | Thought-seed path deep-clones entire conversation on every retry at step 0. | Clone once per turn or use chained iterator / extra-arg API taking `&[Value]`. |

| `daemon/src/agent/compaction.rs` | 687 | `reserved.iter().map(\|ex\| count_messages_tokens(ex)).sum()` | Budget loop re-encodes same exchanges for each `n` (O(n²)); `shrink_live_turn` recounts after every group. | Precompute per-message token array once, sum slices. |

Hub migration priority: fix `app_id` scoping in `hitl_rules`, `mcp/manager`, `router`, `sessions/jobs/execution/timings`, and `health/memory/pathway` routes first — these are direct cross-tenant data/billing leaks. Then eliminate per-turn clones/token recounts and share HTTP clients.
